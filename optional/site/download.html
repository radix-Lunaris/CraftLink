每次更新版本这个值都会变：新 exe 覆盖上去之后， SHA-256 与字节数都会不一样，页面上的这三行要一起改。

拿到文件后可以在 PowerShell 里核对：

算出来的值和上面一致，就说明文件在传输过程中没有被改动过。

Windows 提示「未知发布者」怎么办？

这是正常现象。这是一个个人开发的开源项目，没有购买代码签名证书， 所以 Windows SmartScreen 会显示「未知发布者」。

你可以这样处理：点击提示框里的「更多信息」 → 「仍要运行」； 或者右键文件 → 属性 → 勾选「解除锁定」后再运行。

如果在意安全性，请先用上面的 SHA-256 校验值核对文件， 确认无误后再运行。校验值在文件发布前会保持留空。

需要安装运行库或 Python 吗？

不需要。CraftLink.exe 是打包好的单文件程序，运行需要的东西都在里面， 不用装 Python、不用装 .NET、不用装 Visual C++ 运行库。

如果双击后完全没反应，多半是被安全软件拦下了（见下一条）， 而不是缺运行库。

需要开放端口 / 做端口映射吗？

不需要。不需要公网 IP，不用进路由器后台，也不用在 Windows 防火墙里放行任何入站端口。

数据是客户端主动连出去的，朋友的流量经中继转发进来 —— 你本机的 Minecraft 端口始终只对 127.0.0.1 开放。

杀毒软件/浏览器报毒或拦截下载怎么办？

未签名的个人项目被启发式引擎误报很常见。请只从本页给出的官方入口下载， 不要用来路不明的转载版本。

临时放行前，建议先核对 SHA-256；核对一致后把程序所在文件夹加入白名单， 如果仍然不放心，就先别运行。

要装到 Minecraft 目录里吗？

不用。放在桌面、D 盘任意文件夹都可以，它不会读写你的 mods 目录， 也不会修改游戏文件。不想要了，直接删掉 exe 就行。

怎么确认下载到的文件没被动过？

在文件所在目录打开 PowerShell，运行：

Get-FileHash .\CraftLink.exe -Algorithm SHA256

把输出里的哈希和本页的校验值逐位对比。校验值目前是占位状态， 文件正式发布后会同步更新。
