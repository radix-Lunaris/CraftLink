把你的 Minecraft 世界，
一条链接交给朋友。

CraftLink（方块联机）让「单人存档」变成可以随时开黑的联机世界： 你在游戏里点一下「对局域网开放」，客户端把这个世界经中继服务器转发出去， 朋友只用一个房间名就能进来 —— 不用内网穿透，不用改路由器，不用公网 IP。

为什么用它

三件事，做得刚刚好

不做账号体系，不做启动器，不做模组管理 —— CraftLink 只负责一件事：把你已经开好的局域网世界，安全地送到朋友那台电脑上。

免安装，单文件

一个约 12.4 MB 的 CraftLink.exe，解压到哪都能跑， 不写注册表、不装运行库、不留后台服务。删掉文件就是卸载干净。

  • Windows 10 / 11 直接双击运行
  • 不占用 Minecraft 的 mods 目录，也不改游戏文件

中文房间名

房间用房间名标识，中文、英文、空格都可以，叫「周末生存」的房间和叫 weekend 的房间一样好记。同名就是同一个房间，程序内部自己生成房间 ID。

  • 不用记 IP、端口和一大串随机码
  • 房间名就是口令，说一声朋友就能进

朋友不用装同样的东西

房主在 Windows 上跑客户端；朋友那边只要装一个自己的 CraftLink（同样是这个 exe）， 就能在 Minecraft 里连 127.0.0.1:端口 进入世界。

  • 不要求双方版本、模组、整合包完全一致（以游戏本身能连为准）
  • 多平台的朋友都能接进来，房主的操作始终只有一步
三步开玩

从开世界到朋友进服，大约一分钟

下面是完整流程。真正的点击只有三下：游戏里开局域网、客户端开始连接、朋友在游戏里加入服务器。

  1. 房主：在游戏里开局域网

    进入你的存档，按 Esc → 「对局域网开放」 → 记下游戏给出的端口号。

    Minecraft Java 版 · 单人存档即可

  2. 房主：客户端开始连接

    打开 CraftLink，选主机、填一个房间名（中文也行）、填刚才的游戏端口，点「开始连接」。

    客户端 → 中继服务器 → 隧道就绪

  3. 朋友：用房间名进来

    朋友打开 CraftLink 选玩家、填同一个房间名，然后在 Minecraft 里连接 127.0.0.1:端口。

    同名即同房间 · 不需要公网 IP

房间里的「主机位置」

每个房间有一个 host（主机）位置：谁开世界谁持有它，Minecraft 的连接就绑定在这个位置上。 在客户端按「停止开服」不会释放这个位置 —— 想换人开世界，需要在客户端点 「释放主机身份」，位置才会空出来给下一个人。
