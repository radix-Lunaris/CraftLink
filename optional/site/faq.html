怎么建房（开一个能联机的世界）？
  1. 打开你的 Minecraft Java 版单人存档，按 Esc。
  2. 点「对局域网开放」，游戏会给你一个本机端口号，记下它。
  3. 打开 CraftLink 客户端，身份选主机，填一个房间名（例如「周末生存」）。
  4. 填上刚才记下的游戏端口，点「开始连接」。等状态变成已连接、隧道就绪。
  5. 把房间名告诉朋友，他们就能进来了。

客户端不是启动器：世界还是你在游戏里正常开的那个世界，CraftLink 只负责把它送到朋友那边。

朋友怎么加入？
  1. 朋友下载同一个 CraftLink 客户端，双击运行。
  2. 身份选玩家，填和房主完全一样的房间名，点「开始连接」。
  3. 等客户端提示本地端口就绪后，在 Minecraft 里选择「多人游戏」→「直接连接」。
  4. 地址填 127.0.0.1:端口（端口以客户端界面上显示的为准），加入即可。

房间名要一字不差：多一个空格、少一个空格，都算两个不同的房间。 建议直接复制粘贴房主发来的房间名。

房间名可以用中文吗？重名了怎么办？

可以。中文、英文、空格都支持，叫「周末生存」和叫 weekend 一样正常工作。 房间名就是房间的标识，同名即同一个房间；程序内部会自己生成一个房间 ID 来做实际标识， 你不需要看到也不需要记它。

所以重名不是「冲突」而是「进同一个房间」：如果有人用了你想用的名字，你进去看到的会是他的房间。 起名时加一点自己的特征（比如「房主的名字 + 存档名」）就不会撞车。

为什么需要账号？我要注册登录吗？

客户端不需要注册、不需要登录。打开就能用，填的是房间名和端口，没有任何密码要记。

客户端里会用到你的一个显示名字（用来在房间里区分谁是谁）以及本机自动生成的客户端标识， 这些都是为了「让你顺利进房间、出错时好排查」用的，不涉及任何账号体系。 也正因为没有账号，房间目前不设密码 —— 谁能说出房间名，谁就能进来。 别把房间名发到公开的地方，如果房间名外泄了，换一个名字重新开即可。

「主机身份」是什么？为什么点了停止，别人还是进不来？

每个房间里有一个 host（主机）位置，它是房间里唯一「连着 Minecraft 世界」的位置， Minecraft 的连接绑定在它上面。谁开世界谁持有它，先到先得。

关键点：在客户端点「停止开服」只停止世界，不会释放这个位置。 所以如果队友接手开世界，他会发现位置还被你占着、进不去 —— 这时候需要在客户端点「释放主机身份」，位置空出来后，别人就能接手开世界了。

另外，如果你持有主机身份时断线或关闭了客户端，位置会被自动回收； 但房间不会因为「停止开服」而被销毁 —— 房间的寿命绑定在成员连接上， 你可以随时重新开一个世界接着玩，朋友不用重新加房间。

连不上怎么办？

按这个顺序排查，绝大多数问题在前三步就能解决：

  1. 核对房间名：两边是否完全一致（含空格、大小写、有没有全角空格）。
  2. 确认世界开着：房主那边「对局域网开放」还在，游戏没有退出存档。
  3. 确认主机位置有人持有：如果房主点过「停止开服」，位置不会自动释放，需要点「释放主机身份」或重开一次。
  4. 核对端口：玩家在 Minecraft 里填的端口，要以自己客户端界面上显示的本地端口为准。
  5. 看客户端日志：客户端界面上会显示连接状态和错误原因，「连不上中继」和「房间不存在」是两回事。
  6. 换网络试试：公司/学校网络如果对本机程序有额外限制，可以换手机热点对比一下，能快速判断是不是本地网络的问题。

如果两边都显示已连接但游戏进不去，通常是游戏本身的问题（版本/模组不匹配等）， 可以先在房主本机用 127.0.0.1:游戏端口 直连测试，确认世界本身可以进。

延迟有多少？会卡吗？

我们不在这里写一个固定数字 —— 延迟取决于你和房主分别到中继服务器的网络质量， 写死了只会误导人。客户端界面会显示实时中转延迟，你可以自己看着数字判断。

定性地说：同城、同省的朋友体验接近直连，正常生存、建造基本感觉不到差别； 跨运营商、跨地区会有明显绕路感，比如区块加载慢、挖掘方块有回弹延迟。

中继只转发字节，它不会加速网络。规划中的 STUN 直连就是为了给「两边本来就很近」的情况 找一条更短的路 —— 敬请期待。

要不要钱？有没有内购？

不要钱。没有内购、没有会员、没有广告，也不要求你注册任何东西。 这是一个个人开发的开源项目，客户端完整功能免费使用。

唯一的成本是作者自己承担的服务器开销。如果将来因为规模需要调整， 我们会在站点上明说，而不是悄悄塞限制。

朋友用别的平台 / 别的启动器能进吗？

目前 CraftLink 客户端本体是 Windows 单文件程序， 持房主身份、开世界的人需要在 Windows 上运行它。

玩家一侧的关键动作只有两步：跑客户端 + 在 Minecraft 里连 127.0.0.1:端口。 也就是说，房主在 Windows 上开好房间之后，其他平台的朋友只要能跑起对应版本的客户端， 就能用同一个房间名接进来 —— 我们不会承诺「所有平台都一键可用」， 但会尽量不让平台成为唯一的门槛。

界面能换语言吗？有暗色主题吗？

都能。客户端支持 中文 / English / 日本語 三种界面语言， 主题支持 暗色 / 亮色 / 跟随系统，在客户端设置里随时切换，重启后依然记得你的选择。

顺便说一句，你现在看的这个网站右上角也有主题切换按钮，跟客户端一样支持跟随系统。

安全吗？会不会泄露我的存档？

中继服务器的职责是转发字节：它不解析 Minecraft 协议，不拆包、不改包， 按收到的顺序原样转发。它看不到「这是聊天消息」「那是区块数据」这种含义， 也不会存你的存档文件。

需要你自己注意的两件事：

  • 房间目前不设密码，知道房间名就能进。请把房间名只发给朋友。
  • 进房间的人拥有和你在同一个世界里玩的能力（可以破坏方块、拿箱子里的东西）， 不熟的人不要随便放进来，进游戏后也可以用游戏自带的封禁/白名单管理。
接下来会有什么新功能？

规划中的两项是 STUN 直连与 AUTO 调度： 在「一定能连上」的中继路线之上，再给网络条件好的情况找一条更短的路径。 敬请期待 —— 我们不会写具体版本号和日期，做稳了才会放出来。

中继转发这条路会一直保留：打洞失败必须能自动回落，不允许出现「以前能连、现在连不上」。 更多细节在技术路线页。
