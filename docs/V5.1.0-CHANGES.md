# v5.1.0 — CustomTkinter 桌面 UI（2026-10-26）

## 范围与交付

基于完整 v5.0.1Full 建立独立 v5.1.0Full，原目录保持不变。

- 采用 CustomTkinter 6.0.0：左侧导航、右侧工作台，包含联机、房间大厅、连接状态、运行日志、设置与账号五个页面。
- 提供深色、浅色、跟随系统三种主题；保留中文、英文、日文。登录、修改用户名、成员列表及兼容房间弹窗均改用同一控件体系；房间表格使用与主题一致的原生 Treeview 数据网格。
- 常驻开始／停止按钮；建房／入房、Host 认领／释放、Owner 权限、配置确定与锁定、账号凭据、日志操作沿用原有控制流程。
- 打洞进度下继续逐玩家显示实际路径与 IP；房间成员行复用，状态展示仍从引擎快照读取。重绘 UI 不重建网络引擎。
- 29 个 client/mclink/core 文件逐字节保持 v5.0.1；22 个 Panel 文件、面板镜像、统计与容量规则未改动。服务端仅 VERSION 和 Docker 镜像版本标签更新至 5.1.0。
- 未实现新 API、无界面服务、Host 漂移、存档同步或 Minecraft Mod。

## 代码结构

- client/mclink/gui/app.py：新的 CTk 主窗口、页面、状态行和成员窗口。
- client/mclink/gui/widgets.py：统一 CTk 控件与原控制器颜色更新接口适配。
- client/mclink/gui/controller.py：从上一版保留的 141 个原控制方法，含所有装饰器，AST 与固定清单一致。
- client/mclink/gui/presentation.py：原格式化函数、主题、角色与网络状态文案、资源和单实例入口。
- client/mclink/gui/auth_ui.py：CTk 弹窗；39 个非视图账号方法 AST 与原版一致。
- requirements.txt / requirements-build.txt：固定 UI 依赖；构建脚本收集 CustomTkinter 数据资源。
- docs/ui-controller-baseline.json / ui-preservation.json：控制器及未变范围的核验记录。

## 使用与更新

运行本目录 CraftLink.exe；需要控制台日志时使用 CraftLink-console.exe。原配置路径、client_id 与账号规则沿用。源码运行：

```powershell
python -m pip install -r requirements.txt
python client/main.py
```

构建和检查：

```powershell
python -m pip install -r requirements-build.txt
python scripts/build_client.py
python -B tests/run_all.py
python -B scripts/smoke_ui.py
python -B scripts/audit_ui.py
python -B scripts/check_deploy.py --no-tests
```

既有客户端／服务端严格版本门禁保留，5.1.0 客户端应配套 5.1.0 服务端。将本版本的服务端文件上传原 /opt/mc-link，保留远端 .env 和 panel/config.php，执行：

```bash
bash /opt/mc-link/rebuild.sh relay
```

会重启中继，应在可中断连接时执行。Panel 未改，无需重建。两端使用本目录新 EXE；不将旧版 EXE 改名交付。
