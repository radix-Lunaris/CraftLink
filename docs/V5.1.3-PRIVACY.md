# v5.1.3 地址隐私与发布边界

自有域名从公开默认值、说明和截图移出，不改变网络算法、AUTO 调度、界面布局、用户身份或登录配置。真实地址保留在 Git 仓库外的私有配置中。公开模板只含 `.invalid` 示例地址，不能直接用于连接真实服务。

## 保持自用体验

已有 `mclink_config.json` 优先，包含服务器地址、端口、更新地址、client_id 等原设置，不重置、不迁移身份目录。

首次启动或恢复默认时，公共默认参数按以下顺序取得：

1. `MCLINK_DEFAULT_SERVER_HOST`、`MCLINK_DEFAULT_SERVER_PORT`、`MCLINK_UPDATE_URL` 对相应字段的进程环境覆盖。
2. 私有地址配置中的相应字段。
3. 源码中的示例地址与默认端口。

私有地址配置选择：显式设置 `MCLINK_CLIENT_PROFILE` 时读取指定 JSON；设置为空表示关闭自动查找。未设置时，EXE 从自身旁边读取 `client-profile.local.json`；源码从仓库根目录同名文件读取，其次从仓库外相邻的 `mclan-private/client-profile.local.json` 读取。显式文件缺失或格式无效会报错，不静默改连其他服务器。该配置仅允许 `server_host`、`server_port`、`update_url`，不存数据库或管理凭据。

本工作区原地址已保值导出至上述仓库外私有目录。自用 EXE 与地址文件配套放在该私有目录的 `releases/v5.1.3/`；正常双击即可使用原默认地址，无需手动设置环境变量。公开候选 EXE 不携带地址文件；老用户继续读取原有用户设置。首次为其他使用者指定地址时，在客户端设置中填写，或私下提供地址文件。

## Git 与交付保护

`.gitignore` 用中文分组说明真实环境配置、客户端身份、私有地址、密钥、数据库、日志、历史备份与构建产物的排除规则。模板和源码仍提交。强制加入文件可能绕过忽略规则，因此提交钩子还检查暂存 blob。

仓库外 `publication-denylist.json` 的 `private_values` 数组保存不允许公开的域名等字符串；`check_secrets.py` 自动读取并以不区分大小写的方式扫描。扫描只报告路径和规则，不输出匹配值。新增自有地址可加入这份私有清单；不要把清单本身提交。普通域名本身不是可自动识别的秘密，克隆公开源码的机器没有这份清单，需要自行配置自己的私有清单。

交付枚举独立排除 `.local.json`、敏感清单、私有目录和 Git bundle，不能只依赖 `.gitignore`。构建只打包源码与指定公共资源，不将运行中加载的地址配置嵌入 EXE。自用目录含真实地址，不属于可公开源码包或 Release。

本地未发布的开发历史在私有 Git bundle 备份后重新脱敏：文本移除自有域名，旧截图从旧开发提交中移除，当前截图以示例地址重拍。仅调整本地 dev 的未发布历史，旧作者 legacy、远端分支、标签和发行记录不改动。旧提交 ID 因脱敏改变，历史测试记录中的旧 ID 只表示当时记录；最终产物以本次外部 JSON/SHA256 为准。

旧原始交付、备份包和历史 bundle 仍可能含真实地址或凭据，保留在仓库外，不能整体上传工作区。Git 不会因文件被忽略而清除已有提交；本次单独处理了可达开发历史。原 Git 对象和 reflog 可保留用于本地恢复，普通分支推送不会上传不可达对象；禁止镜像推送整个仓库或上传 `.git`。

## 验收和更新

新增配置测试覆盖示例默认、私有配置、环境覆盖、坏配置拒绝、已有设置优先、Git 忽略、打包排除及大小写域名扫描。验证记录见 `V5.1.3-VALIDATION.json`。29 个网络核心文件保持字节一致，面板继续复用原已验证镜像。本轮不重新部署、不 push、不轮换凭据。

中继与双方客户端同步更新到 5.1.3。公开候选包不含真实 `.env` 或地址配置；VPS 仍遵守先备份／保值迁移，再覆盖、预检和重建的顺序。
