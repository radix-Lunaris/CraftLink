# v5.1.2 桌面调整与远端分支整理

基于 v5.1.1，只调整已授权的桌面显示、开始连接后的页面引导和版本元数据。网络算法、AUTO 调度、房间权限、人数口径与 Panel 业务保持原样。

## 六项界面调整

- 页眉房间名、身份标记使用圆角边框，保留已有状态配色。
- 房间成员窗口相对主窗口居中，作为主窗口所属窗口在打开时抬起；不使用永久 topmost，不阻止切换其他应用。
- 房间大厅改为表格自身滚动，统一标题和单元格对齐，按系统缩放设置字体、行高和列宽。
- 打洞进度下面只为实际启动的网络连接显示行，复用现有行；连接结束即移除，无连接时收起容器。隧道状态仍独立于游戏 TCP，不因服务器列表刷新关闭短连接而隐藏健康隧道。
- 侧栏开始连接按钮在本次启动被接受后跳转连接状态页一次；校验失败、已经运行时不跳转，之后自由切页。
- 连接状态页全部文字加粗，状态、通路和打洞进度进一步放大；浅色主题状态颜色提高对比度，保留颜色语义。

## 验证

真实 CustomTkinter 控件专项检查覆盖深浅主题、圆角、表格标题与内容对齐、状态行 `0 → 2 → 1 → 0`、五页开始连接引导和成员窗口。无连接时打洞行到下一状态项只有 14 个原生像素间距。浅色文字对比度检查通过，回调错误为零。

复核截图在 `docs/ui-preview-v512/`。截图使用示例房间与文档保留 IP，不含真实账号或运行凭据。常规桌面检查覆盖五页、三主题、三语言与三类弹窗；完整回归及最终产物记录见 `docs/V5.1.2-VALIDATION.json`。

29 个网络核心文件必须与冻结基线逐字节相同，原控制器方法按既有 AST 基线检查。本轮逻辑只在桌面视图子类实现。
