# 客户端品牌与用户数据目录（M6）

> 实现范围：`client/**`、`scripts/mclink-client.spec`、`tests/m6_client_config_test.py`。
> 口径来源：`docs/OPENSOURCE-PLAN.md` 的 D8 / D10 / D11 与里程碑 M6。
> 本文写"客户端侧的数据与流程"；**安装器要做什么**见最后一节。

---

## 1. 一句话结论

| 事情 | 结论 |
|---|---|
| 中继服务器地址/端口 | **代码里默认空**。没有内置服务器。用户填写后记忆在用户数据目录。 |
| 登录记忆（用户名/密码） | **默认不记**，用户主动勾选才写盘；老目录里的旧凭据会被清掉。 |
| 日志/配置/记忆/缓存 | 全部写在**用户可选目录**；**绝不写程序安装目录**。 |
| 软件名 / logo / 默认服务器 | 默认取当前项目状态；可由程序目录旁的 `branding.json` 覆盖。 |

## 2. `branding.json`

### 2.1 放哪、谁写

程序启动时按顺序找**第一个存在**的文件：

| 顺序 | 位置 | 谁负责 |
|---|---|---|
| 1 | `$MCLINK_BRANDING_FILE` 指向的路径 | 安装器 / 便携版 / 测试（设了就只看它） |
| 2 | **程序目录**旁的 `branding.json`（冻结 EXE = exe 所在目录；源码运行 = `client/`） | **安装器 / 开发者**（主路径） |
| 3 | 打包进 EXE 的 `branding.json`（PyInstaller 的 `sys._MEIPASS`） | 构建时（可选；`client/branding.json` 存在就会被打进去） |

第 2 条是主路径：**改品牌不用重新打包**。第 3 条是"没有外部文件时的兜底"，
不是把某个真实地址写死进代码。

模板见 `client/branding.json.example`。

### 2.2 字段

| 字段 | 类型 | 默认值 | 作用 |
|---|---|---|---|
| `app_name` | 字符串 | `CraftLink` | 窗口标题、页眉软件名、关于页、日志首行 |
| `logo_file` | 字符串 | 空（用内置 `app.png` / `app.ico`） | 相对=相对 `branding.json` 所在目录；绝对=原样。`.ico` 当窗口图标，`.png/.gif/.ppm` 当关于页图片 |
| `default_server_host` | 字符串 | **空**（没有内置服务器） | 「恢复默认」按钮的目标地址；新装用户的地址预填值 |
| `default_server_port` | 整数 | `0`（= 未设置） | 同上，只接受 1–65535 |
| `update_url` | 字符串 | 空 | 版本不一致时「需要更新」弹窗里的下载页；空则只提示"向管理员索取" |

未知字段被忽略（兼容新旧版本）。

### 2.3 回退规则（一张表）

| 情况 | 行为 |
|---|---|
| 文件不存在 | 全部用默认值；`source=""`；**不报错、不弹窗** |
| 不是合法 JSON / 不是对象 | 全部用默认值 + 一条警告（日志 + 关于页显示） |
| 单个字段缺失 | 该项用默认值（其余字段照常生效） |
| `app_name` 为空串 | 退回 `CraftLink`（窗口标题**不会**变成空） + 警告 |
| `logo_file` 找不到 | 退回内置图标 + 警告 |
| `default_server_port` 非法（`"abc"` / `70000` / `0`） | 按"没有默认端口"处理 + 警告 |
| 字段类型不对（对象/数组） | 该项按空处理 |

警告**不阻塞启动**：品牌是外观与默认值，不是数据通路。

### 2.4 软件名的代码入口

```python
from mclink.config import settings
settings.APP_NAME          # = branding.app_name()，import 时求值一次
settings.version_line()    # "方块特快 v3.9.20 (构建 2026-10-05 17:20)"
```

改 `branding.json` 之后需要**重启客户端**（软件名出现在几十处界面文字和日志里，
中途改名会让日志前后对不上）。logo 同理。

## 3. 中继服务器地址（D10）

### 3.1 默认值

```
ClientConfig.server_host  = branding.json 的 default_server_host（默认 ""）
ClientConfig.server_port  = branding.json 的 default_server_port（默认 0）
ClientConfig.server_source = ""（没确认过）/ "user"（用户填过）/ "branding"（来自品牌默认值）
```

* 空的地址或端口**不会**被任何内置值补上；`validated()` 会拒绝连接并给出
  一段"下一步填什么"的引导（`settings.SERVER_GUIDE` / `SERVER_PORT_GUIDE`）。
* `server_source` 是给迁移用的：**只有 `"user"` 的地址会被原样保留**，
  其余（老配置里那些可能来自旧版内置默认值的地址）在迁移时清掉并提示重新确认。

### 3.2 界面流程

1. **首次运行**（没有配置文件，或地址还空着）：弹出**非模态**「首次使用：连接设置」
   窗口 —— 填什么（地址 + 端口）、填完会怎样（测试成功即记住）、文件存在哪。
   地址框同时获得焦点；关掉之后不再打扰（地址仍空则下次启动还会提示，因为
   空地址 = 连不上，不能静默）。
2. **服务器卡片**常驻一行状态提示：没填 → 引导（橙色）；填了 → "随时可改，
   改完立即生效"；品牌给了默认值时额外标注默认值来源。
3. **测试服务器连接**成功后地址被标记为 `user` 并随配置落盘；下次启动自动带出。
4. **恢复默认**按钮 = 回到 `branding.json` 的默认值；品牌没给默认值时清空两个框
   并明确告知"这个客户端没有内置默认服务器"（不是静默失败）。

## 4. 登录记忆（D11）

* 复选框文案已写明"默认不记"；`credentials.remember_choice()` 在没有任何
  偏好文件时返回 `False`。
* 只有"用户勾选 + 登录成功"之后才会写 `credentials.dat`（加密）与
  `credentials.dat.prefs`（只存一个布尔）。
* 取消勾选 = `clear()`：两个文件都删（"不记住"必须真的不记住）。
* 版本变化时只丢密码、保留勾选（老行为不变）。

## 5. 用户数据目录

### 5.1 默认值

| 平台 | 默认目录 |
|---|---|
| Windows | `%APPDATA%\CraftLink` |
| macOS | `~/Library/Application Support/CraftLink` |
| Linux / 其它 | `$XDG_CONFIG_HOME/CraftLink`（没设就是 `~/.config/CraftLink`） |
| 兜底（默认目录不可写） | 系统临时目录 `CraftLink-<用户名>/`（**不是**安装目录） |

目录里放的东西：

```
<数据目录>/
├── mclink_config.json        # 界面状态（身份、房间、上次用的数字、外观）
├── credentials.dat           # 只有用户勾选"记住密码"才存在（加密）
├── credentials.dat.prefs     # 记住密码的勾选状态（无秘密）
├── logs/                     # 客户端日志（按天轮转，留 5 份）
├── cache/                    # 缓存（当前为空占位，将来功能用）
├── data_dir.txt 的指针在**默认目录**里，不在数据目录里
└── .legacy-migrated          # 老目录迁移完成标记
```

### 5.2 用户改目录时

* **指针文件**：`<默认目录>/data_dir.txt` 记录用户选的目录。它必须待在稳定的
  默认目录里 —— 放进被指向的目录会变成"改了目录就再也找不到用户选的是哪"。
* 优先级：`MCLINK_DATA_DIR` 环境变量 > 指针文件 > 平台默认。
* 指针指向的目录不可用（U 盘拔了/权限没了）→ 本次临时回退默认目录 + 明确提示。
* 界面位置：左列「数据目录」卡片 —— 显示当前目录、`更改…` / `打开` / `恢复默认`。
* 更改时**立刻迁移**：配置/日志/缓存**复制**（不覆盖已有同名文件），
  凭据文件**搬走**（复制成功才删源，不留第二份密码副本）；随后重建日志 handler，
  日志当场写到新目录。旧目录**保留**（不替用户删数据），界面会告诉用户路径。

### 5.3 老版本目录迁移

老版本用过两个目录名（配置和凭据各写各的）：

```
<平台根>/MC-Link        # 老配置（settings.config_dir）
<平台根>/MC-Link 或 ~/MC-Link   # 老凭据（credentials._storage_path，
                                #  Linux 上没设 APPDATA 时会落到家目录）
```

首次以新版本启动时（`client/main.py` 里 `userdirs.ensure_ready()`，**只在这个入口**，
测试直接构造界面不会碰真实目录）：

| 东西 | 处理 |
|---|---|
| `mclink_config.json` | 复制到新目录（保留 `client_id` 等身份，不覆盖已存在的） |
| `logs/*` | 复制（同名不覆盖） |
| `credentials.dat` / `.prefs` | **删除**，并写一条提示告诉用户"需要记住密码请重新勾选一次" |
| 老配置里的服务器地址 | 没有 `server_source="user"` 标记的一律清空（旧版内置默认值不算用户确认），引导用户重新确认 |
| 迁移标记 | 新目录写 `.legacy-migrated`，默认只跑一次 |

凭据为什么是"清掉"而不是"迁移"：老版本那份"记住密码"的意愿是在旧位置、按旧口径
勾的；搬过来会让新版本一启动就自动勾上复选框并回填密码，正是 D11 要禁掉的行为。
删掉源文件同时也避免磁盘上留一份没人再读的密码副本。

## 7. 与安装器的接口（交接）

安装器（Inno Setup / `CraftLink-Builder.exe`，M7）需要做的**只有三件事**：

1. **写品牌文件**：把构建时定好的 `branding.json` 放到**安装目录**
   （和 `CraftLink.exe` 同一层），UTF-8、无 BOM。字段见 §2.2；
   没有品牌需求就**不放这个文件**（客户端会自动用默认值：`CraftLink` + 内置图标 +
   空服务器地址）。
2. **放 logo 文件**（可选）：`branding.json` 里 `logo_file` 指向的图片也要复制到
   安装目录（相对路径就是相对 `branding.json`）。`.ico` 用于窗口图标，
   `.png` 用于关于页。
3. **询问数据目录**（可选）：把用户选的目录写成 `MCLINK_DATA_DIR` 环境变量，或
   让客户端首次运行时自己在界面里改。**不要**把日志/配置写进安装目录 ——
   客户端已经不会了，安装器也不要往那里放运行期文件。默认值就是
   `%APPDATA%\CraftLink`（安装器不指定时客户端自己会用这个）。

客户端**不做**的事：不写注册表、不写安装目录、不假设安装路径（安装器把 exe 放哪都行）。
