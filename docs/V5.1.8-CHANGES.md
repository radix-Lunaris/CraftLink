# v5.1.8 模式切换与 AUTO 路径显示

- 恢复热切换的 20 秒待重建期限。收到服务端模式切换通知后，已有连接会等待新模式广播，再走现有重建流程。
- 两端的 AUTO 路径主标签使用同一份服务端快照。游戏连接和网络隧道分别标注，两端上报未收齐或不一致时显示等待确认或正在同步。
- AUTO 游戏会话结束时记录原因和应用数据字节数，便于将原游戏 socket 的结束与通道故障对应起来。

现场日志显示，AUTO 的部分会话完成 Host 本机连接、双向数据传输及 TCP 结束握手。单凭这些记录无法判断 Minecraft 为何未完成入服。复测时请保留房客的游戏报错、房客客户端日志以及 Host 的游戏服务端日志。

中继和两端客户端需使用同一版本。现场世界入服仍需复测。
