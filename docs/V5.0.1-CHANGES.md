# v5.0.1 — 概览与人数上限（2026-10-26）

## 本轮变更

- 仅移除面板概览的“正在连接”卡片。在线房间、房间内在线、已加入世界、已连接（按成员状态）、空闲隧道、在线账号六张卡片按原顺序排列在同一行；窄屏可横向滚动。其余看板和统计 API／口径不变。
- 服务端面板设置、客户端人数输入及建房校验均支持 2–64 人，包含 Host；默认值仍为 8。服务器 Compose 和新建数据库表的默认值统一为 8。人数说明及相应翻译更新，移除“超过 8 没有意义”的说法。
- 保留原有房间容量／已有设置的生效规则，不自动扩容现有房间、不重置持久化设置。若需要 64 人，在面板将服务器上限设置为 64，并在建房时选择相应容量。
- 版本由 5.0.0 升至 5.0.1，更新客户端、服务端 VERSION、镜像版本标签及构建材料。v5.0.0Full 保留，继续开发与交付使用 v5.0.1Full。

本轮没有修改 AUTO 调度、P2P／UDP 保活、隧道和游戏流生命周期、房间成员状态计算或其他显示。

- 设置保存／重载 64 通过；默认 8、客户端接受 64、拒绝 1／65 的边界通过。
- 本机 Edge 使用实际概览模板卡片和 CSS 渲染：6 张卡片的 Y 坐标均为 72.1875，顺序与要求一致。截图和几何结果见 logs/v5.0.1-overview.png、v5.0.1-overview-layout.json；测试使用静态示例数值，不改变运行统计。

- 面板真实 Docker 构建耗时 55.68 秒，PHP 语法、扩展、FPM/nginx 配置、容器 HTTP 登录页通过；导出新版 amd64 压缩镜像，删除原镜像标签后实际重新载入并再次请求登录页通过。记录见 logs/v5.0.1-panel-result.json，镜像与源文件哈希见 docs/panel-image.json／sha256。
- 其他网络核心与上一交付保持逐字节一致；原始 3.9.20Full 的固定核心未改动。

## 更新

将本目录的服务端内容同步至 /opt/mc-link，包含 images/、docs/panel-image.* 等配套内容；保留服务器原 .env、panel/config.php。Linux amd64 VPS 执行：

```bash
bash /opt/mc-link/rebuild.sh all --prebuilt-panel
```

本次人数上限及版本门禁涉及中继，需同步更新中继与两端客户端。上述命令会重启中继，应在可中断连接时执行；面板使用已验证镜像，无需现场编译。随后两端使用本目录 CraftLink.exe 或 CraftLink-console.exe。

远端数据库、实际站点及多人真实游戏由用户上传后验收；本轮未连接或部署 VPS。

## 版本约定

后续每次可交付修改均递增版本：修复或小范围调整递增补丁号，新增功能视范围递增次版本，不兼容变更递增主版本。客户端、服务端版本和交付材料同步更新，不再统一标记为 v5.0.0。
